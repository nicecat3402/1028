## 一、DDL 與檔案結構

資料庫初始化檔案佈局如下：

```
db/init/
  ├── 01_extensions.sql      # 載入 vector, pg_trgm, pgcrypto 擴充
  ├── 02_schema.sql          # 表結構：companies, company_aliases, departments, contacts, cards, merge_queue
  ├── 03_indexes.sql         # 索引：GIN+gin_trgm_ops, HNSW(vector_cosine_ops), GIN(tags array)
  ├── 04_triggers.sql        # 觸發器：updated_at 自動更新、部門樹同公司檢查約束
  └── 05_seed_title_rank.sql # 職級正規化權重對照表 (95~20)
db/seed/
  └── synthetic_seed.sql     # 合成測試資料 (手動載入)
scripts/
  └── gen_synthetic_data.py  # 合成資料產生腳本 (支援 --seed 42 重現)
```
